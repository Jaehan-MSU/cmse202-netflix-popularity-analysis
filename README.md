# Netflix Content Popularity Analysis

Analyzing whether content features (release year, runtime, genre, country, type, cast/director characteristics) can predict popularity on Netflix, using IMDb and TMDB metrics.

## How to Run

1. Clone the repository. Raw data is included in the repository `data` folder.

```bash
git clone https://github.com/Jaehan-MSU/cmse202-netflix-popularity-analysis.git
```

2. Setup a Python environment and install the required packages:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn
```

3. Run the notebook in order

## Data

- Source: [Kaggle Netflix dataset](https://www.kaggle.com/datasets/victorsoeiro/netflix-tv-shows-and-movies)
- Files: titles.csv, credits.csv
